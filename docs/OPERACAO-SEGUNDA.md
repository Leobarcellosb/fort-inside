# Operação de segunda, 26/10: documentos individuais

Roteiro para quem vai gerar, revisar e enviar os direcionamentos individuais.
Um documento, uma conversa, uma conferência por vez.

## Funções (preencher antes de sábado)

| Função | Quem | Substituto |
|---|---|---|
| Fila: aperta Processar e acompanha até o fim | | |
| Revisão: lê, ajusta e salva cada documento | | |
| Envio: confere o contato e manda pelo WhatsApp | | |

A mesma pessoa pode acumular funções. A meta de 50 documentos entre 9h e 16h dá
cerca de 8 minutos por documento, contando leitura, ajuste, conferência e envio.

## Antes de começar (até 8h)

1. **A chave da IA foi testada** com uma chamada real e dados fictícios, e funcionou.
2. **O formulário está fechado** (o prazo era sexta, 23h59).
3. **As alterações de banco 024, 025, 026, 027 e 029 estão aplicadas.** Sem a 025,
   o botão Entregar não liga. Sem a 027, não dá para tirar documento do ar.
4. Ter em mãos a **lista oficial de contatos** da organização (planilha ou conversas
   individuais já conhecidas). O número que o jovem digitou no formulário não serve,
   sozinho, para conferir o destino. Grupo do evento nunca é destino de documento.

## 1. Gerar (8h)

1. Painel do evento, botão **Processar prognósticos**, confirmar.
2. **Deixar a página do painel aberta** até a seção Prognósticos mostrar que ninguém
   está mais "em andamento". Não existe agendador: a fila só anda com a página aberta.
3. Se aparecer **"Falha no processamento"** ou **"Processamento parcial"**:
   - abra "Ver motivo e tentativas" de uma pessoa e veja a causa;
   - resolva a causa (por exemplo, a chave da IA) e só então use
     **Reprocessar as N falhas**. Sem resolver a causa, falham de novo.

## 2. Revisar (a partir das 9h)

1. **Ir para a revisão.** Cada cartão é uma pessoa.
2. **Editar**, ler o documento inteiro, ajustar o que precisar e **Salvar alterações**.
   Salvar é o ato de aprovar: só depois disso o botão Entregar liga.
3. Texto alterado depois de salvo precisa ser salvo de novo antes de enviar.

## 3. Enviar (um por vez)

1. No cartão revisado, **Entregar**.
2. Confira o **nome completo** na janela e abra a conversa dessa pessoa **pelo contato
   oficial**.
3. Marque **"Conferi no contato oficial que esta conversa é de ..."**. A marcação começa
   desmarcada a cada documento, de propósito.
4. **Disponibilizar documento.** O link passa a funcionar.
5. **Abrir no WhatsApp** (ou Copiar mensagem). A mensagem já vem com o primeiro nome:
   antes de enviar, confira que o nome na mensagem é o da pessoa da conversa.
6. Enviar na conversa. **O painel mostra "Link liberado", não "entregue"**: o sistema
   sabe que liberou o link, não que a mensagem chegou.

Nunca prepare vários links de uma vez para colar depois.

## Se algo sair errado

- **Mandou para a pessoa errada:** no cartão, **Tirar do ar** com o motivo. O link para
  de mostrar o conteúdo na hora. Corrija, salve de novo e reenvie à pessoa certa.
- **Documento com erro de conteúdo já enviado:** o mesmo caminho. O link da pessoa continua
  o mesmo depois de corrigido.
- **O link do documento funciona para quem tiver o endereço.** Não peça para o jovem
  repassar, e não poste em grupo.
